Goal: the word-counting and ranking API of feature F1. Read solutions/P1-word-counter.md in the plan folder
(all sections) and implement its API, algorithm and limits exactly.
- wordstat/__init__.py contains only the docstring """Word statistics.""".
- In wordstat/core.py use from __future__ import annotations, import re and from collections import Counter.
- WORD = re.compile(r"[^\W_]+(?:'[^\W_]+)*")
- count_words(text: str) -> Counter[str] returns Counter(WORD.findall(text.lower())).
- top_words(counts: Counter[str], n: int) -> list[tuple[str, int]] raises ValueError("n must be at least 1") for n < 1.
  Otherwise it returns sorted(counts.items(), key=lambda item: (-item[1], item[0]))[:n].
- Keep inner apostrophes and drop leading and trailing apostrophes. Underscores split words.

Acceptance: write exactly the seven cases of P1 "Acceptance tests" in tests/test_core.py.
1. count_words("The cat and the hat.") == Counter({"the": 2, "cat": 1, "and": 1, "hat": 1})
2. count_words("Don't stop: don't!") == Counter({"don't": 2, "stop": 1})
3. count_words("") == Counter()
4. count_words("route 66, Route 66") == Counter({"route": 2, "66": 2})
5. top_words(count_words("b a b c a b"), 2) == [("b", 3), ("a", 2)]
6. top_words(Counter({"y": 1, "x": 1}), 5) == [("x", 1), ("y", 1)]
7. top_words(Counter(), 0) raises ValueError.
python -m pytest -q → 7 passed.
Check command: if [ -d tests ]; then python -m pytest -q; else echo "no tests yet"; fi (no known failures).

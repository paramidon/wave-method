## Essence

The overnight driver schedules work from an autonomous index or plan, runs each step in a fresh headless Claude session, and writes a morning report with stops, call costs, and review and merge commands.

## How to test

1. Run `python scripts/wave_driver.py plans/2026-11-17-flow-modes/index.md --dry-run` from the feature worktree. Expect one `next: nothing` line with the current waits and no output folder.
2. On an autonomous plan with a pending wave, pass the plan folder and `--dry-run`. Expect the next wave, the Claude command, and its model and caps.
3. Open the linked `report.md` after an autonomous run. Look for feature statuses, unit halts, costs, and the commands to review or merge.

## Worth a look

The final status call runs outside the standard run limits. Use `--no-status` to omit it.
